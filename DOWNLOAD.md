# The Hollow Crown — Android alpha

Native, offline Godot game for ARM64 Android phones/tablets (Android 7.0 or later). This is a development-signed test build. Physical-device performance testing and balancing are still needed.

Download `the-hollow-crown-android.apk` from this branch, transfer/open it on Android, and follow the installation prompt.

Includes a full-screen open-world map, persistent fog of war, a hidden side drawer, settlement markets, trading, contracts, squads, formations, tactical battles, progression, and offline saves.

SHA-256 checksum is in `SHA256SUMS`.
